Logistic Regression — Concepts

What is Logistic Regression?

Logistic Regression is a model that answers yes/no questions. Instead of guessing a number (like a price), it guesses which of two groups something belongs to — for example, "will buy" or "will not buy".

Why is it called a classification model?

The name has "regression" in it, but it is used for classification. The model first calculates a probability (a number between 0 and 1), and then uses that number to decide the final answer: yes or no.

What is Binary Classification?

"Binary" means there are only two possible answers — for example, 0 = No Purchase and 1 = Purchase. The model looks at the data and learns how to separate the two groups.

Independent Variable(s)

The information we use to make a guess. For example: how long someone spent on the website, or their monthly income.

Dependent / Target Variable

The answer we want the model to guess. In this case: did the customer buy something or not.

Classes / Labels

The possible answers. Since this is binary classification, there are only two: 0 and 1.

Probability

The model turns the input data into a number between 0 and 1. This number shows how likely it is that the answer is "yes" (class 1).

Classification Threshold

To turn that probability into a final answer, we use a cutoff point, usually 0.5. If the probability is above 0.5, the answer is "yes" (1). If it's below, the answer is "no" (0).
