Linear Regression — Concepts

What is Linear Regression?

Linear Regression is a supervised Machine Learning algorithm used to predict a numeric value based on the relationship between two (or more) variables. It works by finding the straight line that best fits the pattern observed in the data.

Independent Variable (X)

The input used to make the prediction — the value you already know.

Dependent Variable (Y)

The value the model tries to predict, based on X.

Types of Problems It Can Solve

Any problem where you need to estimate a continuous numeric value from another related variable — for example, predicting sales from advertising spend, or a person's salary from years of experience.

Relationship Between Variables & the Regression Line

When X and Y are related, plotting them produces a pattern — often a roughly straight trend. The regression line is the single line that minimizes the overall distance between itself and every real data point, capturing that trend mathematically as Y = mX + b.

Prediction
Once the line is found, predicting is simple: plug in a new X value, and the line gives you the corresponding Y — the model's estimate.
Simple Example

If houses of 50 m² tend to sell for $50,000 and houses of 100 m² tend to sell for $95,000, a regression line captures that trend — so it could estimate that a 75 m² house sells for around $72,500, even without an exact matching example in the data.
