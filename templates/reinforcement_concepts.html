Reinforcement Learning — Concepts

What is Reinforcement Learning?

Reinforcement Learning (RL) is a type of Machine Learning where an agent learns to make decisions by interacting with an environment. Instead of learning from a fixed, labeled dataset like Supervised Learning, the agent learns through trial and error: it takes actions, observes the consequences, and gradually learns which actions lead to better outcomes.

State

A state describes the current situation of the agent within the environment — for example, its current position in a grid.

Action

An action is a choice the agent can make at a given state — for example, moving Up, Down, Left, or Right.

Reward

A reward is the feedback the environment gives the agent after an action: a positive number for good outcomes (like reaching the goal), and a negative number for bad outcomes (like hitting a wall).

Policy

A policy is the strategy the agent follows to decide which action to take in each state. The goal of training is to find a policy that maximizes the total reward over time.

What is Q-Learning?

Q-Learning is a specific Reinforcement Learning algorithm. It learns a Q-value for every state-action pair, representing how good it is to take that action from that state, considering both the immediate reward and the rewards expected afterward. Over many episodes, these Q-values are updated until they stabilize, and the agent can then simply choose, at each state, the action with the highest Q-value.

Exploration vs. Exploitation

While learning, the agent faces a trade-off: exploring means trying new, possibly unknown actions to discover better strategies, while exploiting means choosing the action already known to work best. A common approach is to explore often at the beginning of training (when little is known) and gradually shift toward exploiting as the agent learns more.

How This Applies to Our Example

In our application, the agent starts at a fixed position on a 4x4 grid and must find its way to a goal cell, avoiding walls along the way. Each move that doesn't reach the goal gives a small negative reward (encouraging shorter paths), hitting a wall or leaving the grid gives a larger penalty, and reaching the goal gives a large positive reward.

The agent repeats this many times (episodes), gradually learning which moves lead to the goal fastest. After training, we can evaluate it by letting it navigate the grid using only what it learned, with no further exploration.
