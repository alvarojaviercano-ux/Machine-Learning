K-Means Application

Dataset and Variable Selection

This page groups {{ record_count }} mobile apps using K-Means, based on the topic assigned to this project: mobile app segmentation by size and user rating.

  • size_mb: the size of the app, in megabytes.
  • rating: the app's average user rating, from 1 to 5.
  • Why these variables: they are the two numbers that best describe an app from a user's point of view — how much space it takes, and how good it is — making them a natural, meaningful pair for grouping apps.
Preprocessing

Before training, size_mb and rating were standardized using StandardScaler. This is needed because size_mb ranges from about 1 to 500, while rating only ranges from 1 to 5 — without scaling, size would dominate the distance calculation and rating would have almost no effect on the clusters.

K-Means Configuration

The model was trained with Scikit-learn's KMeans, using k = 3 clusters (matching the 3 app profiles expected: light and well-rated, heavy and well-rated, heavy and poorly-rated), n_init = 10 (the algorithm runs 10 times with different starting points and keeps the best result), and a fixed random_state so the result is reproducible.
