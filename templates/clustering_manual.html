Final Result and Cluster Characteristics

The algorithm reached its final centroids after the variance stopped decreasing between iterations, meaning the clusters became stable (converged):

  • Cluster 1 ({{ cluster_sizes[0] }} apps): centroid at size_mb = {{ final_centroids[0][0] }}, rating = {{ final_centroids[0][1] }} — smaller apps.
  • Cluster 2 ({{ cluster_sizes[1] }} apps): centroid at size_mb = {{ final_centroids[1][0] }}, rating = {{ final_centroids[1][1] }} — larger apps.
  • Cluster 3 ({{ cluster_sizes[2] }} apps): centroid at size_mb = {{ final_centroids[2][0] }}, rating = {{ final_centroids[2][1] }} — medium-to-large apps.

Since this manual exercise does not scale the variables, the Euclidean distance is dominated by size_mb (which ranges from 0–500) rather than rating (which only ranges from 1–5). This is why the clusters mostly separate apps by size. In the Clustering Application page, the same data (using the full 1,000-app dataset) is scaled before training with Scikit-learn, allowing rating to influence the grouping as well.
