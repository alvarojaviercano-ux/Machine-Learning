Linear Regression - Concepts

What is Linear Regression?

Linear Regression is a simple Machine Learning method used to predict a number based on another number. It finds a straight line that fits the data as well as possible.

What types of problems can it solve?

Linear Regression is used when we want to predict a number, not a category. For example, predicting a price, a temperature, or a distance.

Independent Variable

This is the input value we already know. We use it to make the prediction. It is usually called "X".

Dependent Variable

This is the value we want to predict. It depends on the independent variable. It is usually called "Y".

Relationship Between Variables

Linear Regression assumes that when X changes, Y changes in a steady way. For example, more area usually means a higher price.

Regression Line

This is the straight line the model creates after learning from the data. It shows the general pattern between X and Y, even if the real data points do not fall exactly on the line.

Prediction

Once the model has the regression line, we can give it a new X value, and it will return a Y value using that line. This is the prediction.

Simple Example

If we know the area of many houses and their prices, Linear Regression can learn the pattern between area and price. Then, if we give it a new area, it can predict the price for that house.
