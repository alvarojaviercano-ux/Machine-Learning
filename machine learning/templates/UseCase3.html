Use Case 3: Fraud Detection in Banking

Name of the use case: Fraud Detection in Banking

Problem context: Banks process millions of transactions every day, and some of them are fraudulent. Finding fraud manually is very slow.

Data that could be used: Transaction amount, location, time, and the usual spending pattern of each customer.

What the model should predict: Whether a transaction is fraudulent or normal.

Type of Machine Learning applied: Supervised Learning (Classification).

Potential benefit: Fraud is detected faster, protecting customers' money and reducing losses for the bank.
