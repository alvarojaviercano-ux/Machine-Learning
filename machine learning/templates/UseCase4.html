Use Case 4: Self-Driving Cars

Name of the use case: Self-Driving Cars

Problem context: A car needs to make safe decisions in real time, like when to stop, turn, or speed up, based on its surroundings.

Data that could be used: Camera images, sensor readings, distance to other cars, and traffic rules.

What the model should discover/decide: The best action to take at each moment (e.g., brake, turn, or continue).

Type of Machine Learning applied: Reinforcement Learning.

Potential benefit: Fewer accidents, and safer, more efficient transportation.
