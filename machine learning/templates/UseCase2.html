Use Case 2: Movie Recommendation

Name of the use case: Movie Recommendation System

Problem context: Streaming platforms have thousands of movies, and users often do not know what to watch next.

Data that could be used: User viewing history, ratings, genres watched, and what similar users have liked.

What the model should predict: Which movies a user is likely to enjoy.

Type of Machine Learning applied: Unsupervised Learning (Clustering) combined with Supervised techniques.

Potential benefit: Users find content they like faster, and the platform keeps users engaged longer.
